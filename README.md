# AERIS — Cycling Lifestyle 🚴‍♂️

> **Modern cycling essentials, gear, apparel, and accessories for every ride.**

AERIS is a modern cycling lifestyle concept focused on the equipment, apparel, accessories, and everyday essentials that make cycling more enjoyable both on and off the bike.

The project combines a clean sports aesthetic with an editorial lifestyle approach, creating a storefront that feels energetic, premium, and practical rather than like a generic online catalog.

---

## 🚴 Brand Philosophy

AERIS is built around a simple idea:

**Ride further. Live lighter.**

The brand celebrates cycling as more than transportation or exercise. It is a lifestyle built around movement, exploration, routine, community, and personal freedom.

The website is designed to communicate that philosophy through:

- Strong cycling imagery
- Clean product presentation
- Modern typography
- Athletic visual details
- Practical product organization
- Outdoor and urban lifestyle scenes
- Responsive shopping experiences

## 🚀 GitHub Pages

AERIS is designed to work as a static GitHub Pages project.

### Basic deployment

1. Upload the project files to the repository.
2. Open **Settings → Pages**.
3. Select the desired branch.
4. Select the repository root as the source.
5. Save the configuration.
6. Wait for GitHub Pages to publish the site.

The project should include `.nojekyll` when needed to prevent unwanted processing of static assets.
